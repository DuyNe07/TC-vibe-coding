# Tài liệu gốc về nghiệp vụ

Hai loại file nằm ở đây:

1. **Ghi chép tìm hiểu** `<chủ_đề>-discovery.md` - do AI viết ở bước 0.5
   ([docs/prompt/00-discovery.md](../../prompt/00-discovery.md)) sau khi hỏi - đáp với bạn. Đây là file duy nhất AI
   được phép tạo trước khi có tài liệu nghiệp vụ chính thức.
2. **File mô tả của bạn**: Excel mẫu, quy trình Word, PDF, ảnh chụp màn hình... nếu không tiện đính kèm trong chat.
   Bước 0.5 và bước 1 sẽ tự đọc toàn bộ thư mục này.

Lưu ý: file ở đây sẽ được đưa lên git cùng dự án. Không đặt dữ liệu mật (lương, thông tin cá nhân...) nếu dự án
được chia sẻ; hãy dùng dữ liệu mẫu thay thế.
